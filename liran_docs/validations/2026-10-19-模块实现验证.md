创建日期：2026-10-19；远端交付更新：2026-10-20。任务：`IMAGE-EDITOR-MODULE-20261019-01`。范围仅限当前独立图像编辑模块仓库；没有修改新品测试项目或另外四个应用。

## 代码与文档结果

- 建立可移植模块源码：`src/core/`、`src/react/`、`src/server/`、`src/adapters/apimart/`，并提供 React + Express 本地 mock 示例。
- 增加类型/输入校验、提示词合同、单图服务调用、严格 PNG 标注读取、Sharp 合成、请求超时与结构化错误。
- APIMart provider 通过注入式 fetch 验证上传、任务提交/轮询和 string/array 图片结果；仅在明确 HTTP 451 拒绝时做一次安全澄清重试，保留完整原提示词。没有真实网络调用、没有读取任何密钥。
- 实际浏览器测试发现标注画布在宽幅容器被拉伸导致显示错位。将 canvas 改为按 `object-fit: contain` 居中呈现，并给示例 SVG 写入与服务端解码一致的 900×1120 物理尺寸。修复后再次绘制，截图可见笔迹落在对应图像坐标；带标注请求通过尺寸校验。
- 在 mock 页面手工输入文本、绘制标记并提交；模拟服务失败后弹窗关闭并重新打开，文本和标记保留；再次提交成功，宿主显示成功回调。所有请求仅到本机 Express mock。
- 调整构建顺序为 Vite 先构建、模块后构建，避免 Vite 清空 `dist/` 时一并移除可分发模块入口。
- 更新 Harness 检查器，要求实际模块入口、关键测试、演示与构建脚本、package exports 同时存在；补充错误导出负例。
