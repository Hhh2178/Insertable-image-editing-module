# IMAGE-ITERATION-20261020-01 实施方案

状态：PRD 1.0 已确认。三个目标均已完成；实际命令、页面验收及未覆盖范围见[开发追踪](../04-开发追踪.md)和[实施日志](../logbooks/2026-10-20-图像迭代链路方案记录.md)。

## 范围

仅修改本独立模块仓库。保持原图像编辑 API 和单图 Nano Banana 合同兼容；新增指导重生作为显式可选入口。普通生图和指导 LLM 由宿主服务端注入。示例只使用本地 mock，不读取密钥、不发外网请求。宿主业务类型保持泛型/`unknown`，不导入新品应用的商品或策划类型。

## 目标 1：文档、接口与验收门禁

1. 将已确认 PRD、候选方案同步到架构文档，冻结可选模块入口、数据流、错误阶段和禁止跨层依赖。
2. 建立微观文件/任务拆分，逐项映射 REQ/AC，明确测试先行顺序和回退范围。
3. 定义模板 JSON、输出校验、服务注入、pending 候选及只重试生图的合同。
4. 将新增验收加入测试清单，并补 UI 壳页面检查记录模板。
5. 执行 Harness 与 Markdown 链接/差异检查；通过后将目标 1 标为完成。

目标 1 不改产品源码。

## 目标 2：UI 壳与 mock 页面

1. 在目标模块示例中设计三种操作入口：按当前方案重抽、带指导意见重生、图像编辑。
2. 单独设计指导弹窗，显示可选输入和字数计数；空内容提示将直接按当前方案重抽。
3. 设计派发前、改写中、生图中、失败可恢复、生成成功并追加版本等页面状态。
4. 在 mock 页面检查深色紫蓝视觉层级、卡片图片比例、版本缩略条、状态提示、弹窗关闭时序和错误可读性。
5. 记录实际页面观察、问题与修正；mock 页面不得声称模型编辑质量已验证。

目标 2 不连接真实模型或宿主，不改变版本持久化范围。

## 目标 3：服务实现、mock 集成与验收

按 TDD 小步实施，每个能力先新增一个会因功能缺失而失败的测试，再写最小实现并复测：

1. `guidance` core：模板版本、输入边界、严格 JSON 结构验证及安全错误。
2. `guidance/server`：注入 context loader、rewrite、业务 plan validator、image generator、保存候选/结果回调；空指导跳过 rewrite；改写成功后传完整 prompt；失败后 image-only retry 不重复 rewrite。
3. React 指导弹窗和三操作入口：派发后关闭，来源快照固定，失败恢复草稿。
4. 本地 Express/React mock：本地产生可显示的安全结果 URL，三条链路都追加会话版本，并分开保存完整 `generationPrompt` 与 `operationPromptUsed`。
5. 明确区分 unknown submission、rewrite、validate、generate、store 错误阶段；图像编辑原服务不改语义。
6. 更新包 exports、browser boundary、Harness、README、接入指南和验证记录。

## TDD 验收顺序

| 顺序 | 先写失败测试 | 实现边界 | 主要验收 |
| --- | --- | --- | --- |
| 1 | 模板及结果 schema | `src/guidance` | 空/超长、额外字段、blocked、完整 prompt |
| 2 | 编排次数与直传 | `src/guidance/server` | 非空 1 次 rewrite + 1 次 image；空白 0 + 1；失败不生图 |
| 3 | pending 与重试 | guidance server | 生图重试不重写；source ID 固定；未知受理不自动重提 |
| 4 | 指导 UI 时序 | `src/react` | 计数、空指导分流、派发关闭、失败恢复、重复点击防护 |
| 5 | mock 结果/版本 | example app/server | 三路径可见结果、版本来源、prompt 字段区分 |
| 6 | 包与隔离 | build/scripts/docs | 原 exports 保持；浏览器无服务端代码；Harness 通过 |

## 回退与风险控制

- 新能力以新增子路径导出；原四个入口不改变实现语义。
- 发生兼容问题时，可回退新增 `guidance` 入口及示例改动，不动旧图像编辑服务。
- 改写输出只是候选；模块做结构校验，宿主做领域校验。不能由 LLM 改模型路由、引用素材或权限。
- HTTP 提交受理未知时不自动再发付费请求；示例 mock 仅验证控制流。
- 不进行真实宿主接入、付费模型调用、发布、提交或推送。
