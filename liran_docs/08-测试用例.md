# 验收与测试清单

本文件映射已确认 PRD 的 AC-01 至 AC-10；本目标执行证据另记于[开发追踪](04-开发追踪.md)及[页面检查](09-真机实测.md)。Harness 通过不能代替产品验收。

| 编号 | 范围 | 成功条件 | 执行边界 |
| --- | --- | --- | --- |
| H-01 | 文档路由 | 规则、README、03/04、需求、PRD、评分、架构、接入指南、模块拆解、计划、测试、日志和验证存在，内部链接有效 | 本轮离线检查 |
| H-02 | 凭证/路径 | `.env` 与实际凭证忽略，内部路径可移植，无本机绝对路径 | 不读取 `.env` 内容 |
| H-03 | 命令 | README 与 package.json 声明匹配，检查器异常输入确实失败 | 本轮 Harness 测试 |
| AC-01 | 模块分层与独立性 | 干净 checkout 安装/构建 mock；browser 不含 Node/Sharp/key；不得耦合来源项目 | 目标 3 自动验证；来源耦合或层越界即失败 |
| AC-02 | 编辑输入与画笔 | 必填/2,000 字、工具集、contain 坐标、源图不变 | 目标 2 mock 页面+目标 3 单测 |
| AC-03 | 草稿与派发时序 | 准备失败留窗、派发关闭、错误可恢复、重复提交防护 | 目标 2 mock UI，目标 3 transport 测试 |
| AC-04 | 提示词合同 | 单图标注前缀、原文保留、保真后缀、中英/混合语义 | 目标 3 core 测试 |
| AC-05 | 图片合成/单图/loader | 受控读取、字节/像素限制、有标记合成无标记原图、provider 只收一张 | 目标 3 server 图像合同 |
| AC-06 | APIMart adapter | Nano Banana 2.1/auto/1K、上传/轮询、string/array URL 和异常 | 目标 3 provider mock |
| AC-07 | 来源 ID 与宿主版本 | operationId/sourceId 固定；成功由示例 host 追加到原来源 | 目标 3 集成示例 |
| AC-08 | 安全错误与重试 | 分阶段安全错误、敏感内容脱敏、unknown 不重提、安全重试限制 | 目标 3 service/adapter tests |
| AC-09 | 独立演示和接入文档 | 无来源 checkout、无真实 key 的独立安装构建与 mock 运行 | 目标 3 干净环境检查 |
| AC-10 | 范围与内部验收 | 只改模块仓库；测试、类型、构建、mock 页面通过；无真实模型请求 | 目标 3 收口审计 |
